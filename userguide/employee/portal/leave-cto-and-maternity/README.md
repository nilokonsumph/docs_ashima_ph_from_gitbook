# request and track leave, CTO, and maternity

use this area to understand the benefit or balance first, submit the correct request, follow every approval status, and review the source transactions when a balance is unclear.

start with the article that matches the record:

* ordinary leave explains assigned leave types, **Apply** availability, balances, approval history, the transaction ledger, and cancellation;
* CTO explains how approved work becomes time-off credit, how the balance is reserved and used, and why it can expire; and
* maternity explains the application, source records, calculation, approval, and later record review.
