# definition of terms

| term                    | meaning                                                                                                                                             |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| attendance exception    | an absence, tardiness, undertime, missing punch, overtime, or open-shift condition that needs review                                                |
| available leave balance | credits currently available for a new request after applicable reservations and recorded movements                                                  |
| CTO                     | compensatory time off created when eligible approved overtime, rest-day work, or holiday work is converted into time-off credit under company rules |
| CTO conversion          | the process that creates CTO credit and excludes the same source work from being paid again in payroll                                              |
| De Minimis              | a supported employee benefit with its own non-taxable limit; an amount above the applicable limit is called excess De Minimis                       |
| disbursement            | a record showing how an approved amount was prepared or recorded for release; it is not by itself proof that money reached an external account      |
| gross pay               | taxable pay plus non-taxable pay before total deductions                                                                                            |
| net pay                 | gross pay less total deductions                                                                                                                     |
| other benefits ceiling  | the annual ₱90,000 non-taxable limit shared by 13th Month and qualifying other benefits; it is not a separate limit for each item                   |
| open shift              | recorded work that follows the supported open-shift path instead of a normal assigned-shift match                                                   |
| payslip                 | the employee-facing result for one completed payroll period after the payslip has been generated                                                    |
| pending leave           | requested credits reserved while an application is waiting for approval                                                                             |
| PPA                     | post-payroll adjustment; the supported process for carrying an eligible correction from a closed payroll into an applicable open payroll            |
| retroactive pay         | a prior-period difference brought into a later payroll after an eligible effective-dated change or correction                                       |
| recovery code           | a one-time fallback code used when an authenticator code is unavailable                                                                             |
| shift                   | the approved schedule that gives context to timesheet punches and attendance results                                                                |
| timesheet application   | a submitted request to add or change a timesheet punch                                                                                              |
| transaction ledger      | the history of earnings, reservations, approved use, returns, adjustments, transfers, conversions, expiry, and the resulting leave or CTO balance   |
| workflow                | the configured approval path that sends a submitted request to the applicable approver                                                              |
| 2FA                     | two-factor authentication; an additional sign-in check using an authenticator or recovery code                                                      |
