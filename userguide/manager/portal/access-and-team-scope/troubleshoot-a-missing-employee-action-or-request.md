# troubleshoot a missing employee, action, or request

use the smallest check that matches the problem:

| problem                                      | what to check                                                                                                   |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Manager portal is missing                    | correct company, active manager assignment, and Manager access enabled                                          |
| employee is missing everywhere               | employee company/status, **Reports To**, department, and your scope                                             |
| employee is visible but an action is missing | the function assigned for that scope and the specific add, edit, delete, apply, or download access              |
| an Hours change is blocked                   | payroll freeze, work date, current record state, and edit/delete access                                         |
| a leave action is missing                    | leave view plus the separate apply, edit, cancel, or delete action                                              |
| a To Do category is empty                    | no pending request, request assigned to another approver or level, completed status, or missing approval access |
| a shift or timesheet result looks wrong      | assigned shift first, then punches, leave, overtime, and request status                                         |

capture the employee, company, page, date, expected action, visible message, and request or record identifier before contacting the administrator. do not ask for broad access when one employee relationship or one task action is the missing control.

## use the result to choose the owner

* ask HR to correct the employee's company, status, department, or **Reports To** relationship;
* ask the Manager Access administrator to correct employee scope or task permission;
* ask the Workflow administrator to correct an approver level or pending assignment; and
* ask payroll to review a frozen or closed period.

refresh the page after the owning record is corrected and test the same employee and action again.
