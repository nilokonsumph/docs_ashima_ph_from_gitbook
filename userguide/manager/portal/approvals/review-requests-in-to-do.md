# review requests in To Do

use **To Do** for requests currently assigned to you as an approver. choose the category that matches the request:

* **timesheets**;
* **rest day**;
* **holiday**;
* **mobile clockin**;
* **open shifts**;
* **overtime**;
* **leave**;
* **shifts**; and
* **maternity**.

an empty category means no request is currently listed there for your account. check any search or filters, then ask the workflow administrator to check the request's current approver if you expected to see it. manager access to team records and assignment as an approver are separate controls.

payroll, disbursement, 13th Month, year-end, termination, and document approval work is covered in the [administrator To Do and Workflow guide](../../../admin/todo-workflow/). those responsibilities do not follow automatically from access to Manager Portal.

## choose what to review

| request                                            | compare before deciding                                                                           |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| timesheet, rest-day, holiday or open-shift request | employee, work date, assigned shift, captured punches and requested hours or correction           |
| overtime                                           | the requested overtime period and the employee's worked timesheet hours                           |
| leave or maternity                                 | the requested dates, applicable balance or benefit details, reason and supporting documents shown |
| shift change                                       | current and requested schedule, affected dates and any existing punches                           |
| mobile clock-in                                    | the submitted punch and supporting information displayed with the request                         |

for the step-by-step Leave example and how to confirm a decision, see [approve or reject a request](approve-or-reject-a-request.md). if a request cannot be acted on, see [understand locked, closed, and reassigned approval work](understand-locked-closed-and-reassigned-approval-work.md).
