# definition of terms

| term                        | meaning in this guide                                                                                                                               |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Manager portal**          | the Ashima portal for team records and actions assigned to a manager                                                                                |
| **Employee portal**         | the portal for your own employee schedule, timesheet, requests, and pay records                                                                     |
| **Direct Reports**          | employees connected to you through their **Reports To** relationship, including additional levels only when configured                              |
| **Department scope**        | employees included because they belong to departments selected for your manager access                                                              |
| **Manager Access Settings** | administrator-owned controls that combine employee scope with the Manager portal functions allowed for that scope                                   |
| **available leave balance** | credits currently available for a new employee request after applicable reservations and recorded movements                                         |
| **CTO**                     | compensatory time off created when eligible approved overtime, rest-day work, or holiday work is converted into time-off credit under company rules |
| **CTO conversion**          | the process that creates CTO credit and excludes the same source work from being paid again in payroll                                              |
| **timesheet**               | the employee's captured time punches and resulting workday record                                                                                   |
| **shift**                   | the schedule context used to interpret expected work, breaks, rest days, and time punches                                                           |
| **leave ledger**            | the transaction history that produces an employee's current leave or CTO balance                                                                    |
| **To Do**                   | the queue of requests currently assigned to an approver for action                                                                                  |
| **workflow**                | the configured approval path, levels, and approvers for a request family                                                                            |
| **payroll freeze**          | a control that limits changes for a pay period and can affect which approval actions remain available                                               |
| **scope**                   | the employee population to which assigned Manager portal functions apply                                                                            |
