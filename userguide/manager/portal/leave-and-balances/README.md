# review leave, CTO, and balances

use this area to answer three different questions:

* **what happened to the request?** review leave history and approval status;
* **how was the current balance produced?** review the leave or CTO transaction ledger; and
* **what action is needed?** file an authorized request or use the specific correction or cancellation action assigned to you.

ordinary leave and CTO share the leave area but do not have the same source. ordinary leave usually comes from an assigned or accrued policy. CTO is created from eligible approved work converted into time-off credit.
