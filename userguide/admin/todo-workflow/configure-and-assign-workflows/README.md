# configure and assign Workflows

Use this area to create the supported approval route and assign it at the scope allowed for that Workflow type.

Some Workflows are global, some allow several employee assignments, and some can be assigned more specifically, such as by leave type. Review the default Workflow, approval levels, backup approvers, notification options, and existing pending work before replacing or reassigning a route.
