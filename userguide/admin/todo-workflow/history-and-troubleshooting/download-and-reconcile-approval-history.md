# download and reconcile approval history

## download and reconcile approval history

use **History** or the download action in a supported queue when you need a retained record of decisions for a selected period.

1. open the applicable **Todo** category.
2. select **History** or the supported download control.
3. enter the available date range and filters.
4. generate the file.
5. compare the employee or batch, source identifier, status, approver level, action date, and source-module result.

**Download a copy** in a confirmation captures the selected records before the decision. a history download reports prior actions. use the one that matches the audit question.

do not treat an exported approval row as proof that every downstream calculation, notification, file, or payment completed. reconcile with the owning module and output when that result matters.

if the wrong dates or filters were used, generate a new history file with the corrected scope. history files are evidence outputs; generating another file does not alter the saved approval decisions.
