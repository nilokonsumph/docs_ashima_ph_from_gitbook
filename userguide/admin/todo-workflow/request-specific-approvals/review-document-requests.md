# review document requests

## review document requests

use **Todo → Document** to review employee document requests routed through the configured Document Workflow.

confirm the employee, requested document type, request date, supplied information, approver trail, and the source record used to produce the document. approve only when the source data is complete and the request belongs to the correct employee and company.

after the final decision, verify the request status and the supported document-generation or delivery step in the owning Documents page. an approval state does not by itself prove that an external recipient received a document.

### review and decide one request

1. search for the employee or use the available filters, then open the intended request.
2. check the employee, document name and type, requested date, status, approver trail and displayed document body.
3. for a pending request that you are eligible to decide, select **Approve** or **Reject**.
4. check the confirmation and select **yes, approve it!** or **yes, reject it!** for your decision. the confirmation has no reason field. **Cancel** leaves the decision unsubmitted.
5. correct any error shown in the confirmation. after success, check the request's status in the Document queue.

### decide several requests

1. review each request before selecting it in the list.
2. choose **Approve selected** or **Reject selected**. use **Approve ALL Items** or **Reject ALL Items** only after checking the returned eligible requests; **ALL** does not guarantee that every company request is selected.
3. verify the number of requests in the confirmation. use **Download a copy** before deciding if you need a record of the selected requests.
4. confirm the intended decision, or choose **Cancel**.
5. check the response and refreshed statuses. a saved rejection does not confirm that its notification email was delivered.

for the request and approved output, see [assign and print Workforce documents](../../utilities-documents/assign-and-print-workforce-documents.md).
