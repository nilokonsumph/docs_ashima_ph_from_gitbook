# start here: manage approvals

## start here: manage approvals

use **Todo** to review work routed to you. use **Settings → Workflow** to decide which approvers receive supported requests and the order in which they decide them.

### understand the difference between Workflow and Todo

| part          | what it controls                                                                                                                 | what it does not control                                                  |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **Workflow**  | the workflow name, one to five approval levels, approvers at each level, staff notification, and supported employee assignments  | the business content of a request or its calculation                      |
| **Todo**      | the pending requests visible to the signed-in user, review details, approver status, and supported approval or rejection actions | who was configured as the approver or how the source value was calculated |
| source module | the request, calculation, schedule, balance, payroll, document, or payment being decided                                         | the general approval order                                                |

a request begins in its source module. Workflow identifies the current approval level. **Todo** gives the authorized approver a place to review and decide it. the source module remains the authoritative place to correct and resubmit rejected work.

{% hint style="warning" %}
**important:** approval does not prove that a source value is correct. review the source record, applicable settings, warnings, and downstream effect before deciding.
{% endhint %}
