# find approval work in Todo

## find approval work in Todo

open **Todo** when you need to review requests assigned to you or inspect pending work available through your administrator access.

**Navigation:**\
go to **Todo**.

### read the status indicators

the category cards use indicators rather than numeric request counts.

| indicator     | meaning                                                                  |
| ------------- | ------------------------------------------------------------------------ |
| red           | you have pending work as an assigned approver                            |
| white         | pending work is visible through administrator display or view-all access |
| red and white | both conditions apply                                                    |
| no indicator  | neither condition currently applies                                      |

the indicator tells you that matching work exists. it does not say how many requests exist or that every visible request is actionable by you.

### understand which categories can appear

shared request categories include **Timesheets**, **Rest Day**, **Holiday**, **Mobile Clock-in**, **Open Shifts**, **Overtime**, **Shifts**, **Leave**, and **Maternity Benefits**. administrator-only categories include **Payroll**, **Documents**, **Disbursement**, **13th Month**, **Year End**, and **Termination**.

the categories and rows you see can vary with your privileges, assigned Workflow, company modules, confidentiality scope, filters, and pending records. **Open Shifts** is a review surface in the current Todo page; it does not provide the same approve and reject controls as the actionable attendance queues.

### find the request you need

1. open the applicable category.
2. search for the employee, run, batch, or request when search is available.
3. apply only the filters needed for the decision.
4. clear the search and filters before concluding that a request is missing.
5. open the row or its supporting details.
6. confirm that the action is assigned to you at the current level.

{% hint style="info" %}
**note:** view-all access can make a request visible without making it your turn to approve. use the displayed approver levels and action state to distinguish visibility from authority.
{% endhint %}
