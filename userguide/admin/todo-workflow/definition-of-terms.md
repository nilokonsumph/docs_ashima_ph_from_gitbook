# definition of terms

| term                     | meaning                                                                                              |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| approval level           | one sequential stage in a Workflow; levels proceed in order                                          |
| approver                 | an authorized account assigned to decide a request at a level                                        |
| current level            | the approval stage that can presently be completed                                                   |
| default Workflow         | the protected starting Workflow for a supported process                                              |
| employee-scoped Workflow | a Workflow assigned to particular employees for a supported process                                  |
| final approval           | completion of the last configured approval level                                                     |
| source module            | the part of Ashima that owns the request, calculation, or record being decided                       |
| Todo                     | the administrator or manager workspace for pending approval work                                     |
| view-all access          | visibility into matching requests beyond the signed-in approver's own assigned actions               |
| Workflow                 | the configured approval name, levels, approvers, and supported notifications or employee assignments |
