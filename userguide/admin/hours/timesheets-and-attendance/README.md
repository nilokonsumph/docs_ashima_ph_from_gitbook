# review timesheets and attendance

Use this area to understand the configuration and schedule context behind a timesheet, review captured logs, add or correct supported records, and interpret attendance, tardiness, and undertime.

A timesheet records the logs. The assigned shift supplies the schedule, required punches, breaks, and timing context used to interpret those logs. Correct the owning source and verify the recalculated result before payroll.
