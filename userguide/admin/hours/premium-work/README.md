# review premium work

Use this area to review overtime, rest-day work, and holiday work from their source request through approval and Hours history.

Confirm the employee's shift, date type, approved request, and applicable company rules. Similar hours can have different treatment when the schedule, rest day, holiday classification, or approval state differs.
