# reconcile Hours with payroll and reports

Use this area before payroll or export to compare Hours records with attendance, paid-hours, and audit outputs and to resolve differences at their source.

A report is evidence from a selected source, period, and status. Verify the same employee, dates, shift context, and approval state before comparing totals, then recalculate or regenerate the downstream result when required.
