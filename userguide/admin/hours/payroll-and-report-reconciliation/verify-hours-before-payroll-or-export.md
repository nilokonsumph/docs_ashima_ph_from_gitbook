# verify Hours before payroll or export

use the page filters before downloading. exports reflect the selected view and can enforce row or date limits. after any source change, verify:

1. the employee's schedule and special-day classification;
2. the time sequence, source, and break fields;
3. attendance, tardiness, undertime, overtime, rest-day, holiday, leave, and night-differential results;
4. approval status where required;
5. CTO conversion state where applicable;
6. the selected report period, pay-date scope, and optional paid-hour categories; and
7. the recalculated open pay run.

if an export or payroll result does not match the reviewed Hours data, correct the earliest incorrect source shift, time entry, leave, setting, employee entitlement, or approval record. recalculate Hours, then recalculate the open pay run before generating the output again.
