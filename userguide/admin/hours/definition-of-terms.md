# definition of terms

| term               | meaning                                                                                                                                                                                               |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **time log**       | stored clock-in, clock-out, and break record for an employee and shift date                                                                                                                           |
| **recalculation**  | reinterprets a time log using current schedule, holiday, leave, and timekeeping rules                                                                                                                 |
| **In Sync**        | the Hours page reports no queued recalculation for the displayed status panel                                                                                                                         |
| **missing punch**  | an expected clock or break event is absent                                                                                                                                                            |
| **excess log**     | a captured entry that cannot be matched to the assigned shift's recognized punch sequence or work period; it remains visible for traceability but is excluded from actual, regular, and payable hours |
| **No Show**        | employee has no qualifying clock-in for the expected schedule window                                                                                                                                  |
| **undertime**      | credited work is below the expected schedule under the applicable rules                                                                                                                               |
| **tardy**          | clock-in exceeds the applicable schedule and grace-period rule                                                                                                                                        |
| **PPA**            | post payroll adjustment used for an eligible correction after payroll has closed                                                                                                                      |
| **soft deletion**  | record is inactivated and marked deleted from Hours while its audit and related history remain                                                                                                        |
| **CTO conversion** | converts eligible approved work into compensatory time credits and excludes successfully converted source work from payroll                                                                           |
