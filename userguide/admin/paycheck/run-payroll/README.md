# run payroll

Use this area to move regular payroll from an open draft through review, approval, closing, and payslip release.

## follow the payroll sequence

1. confirm the Paycheck configuration and find the correct pay period.
2. create the pay run for one payroll group and pay date.
3. recalculate and review employee-level payroll details.
4. continue to the Payroll Masterlist and resolve readiness checks.
5. include or exclude employees before submission.
6. send a Pay Draft when employees should review preliminary figures.
7. submit payroll for approval and resolve any rejection.
8. after payroll closes, generate and review the payslip output.

Use [corrections, controls, and ingestion](../corrections-controls-and-ingestion/) when the open pay run needs a direct correction, an imported payroll input, or a control such as Payroll Lock.
