# import and review beginning balances

## import and review beginning balances

use Beginning Balance to record payroll and tax values that Ashima must carry forward even though the source amounts were not produced by the current Ashima payroll history.

{% hint style="warning" %}
beginning balances affect payroll and tax reporting. Use an approved source document and the latest Ashima import template. Do not estimate missing values.
{% endhint %}

**Navigation:**\
go to **Paycheck → Earnings → Beginning Balance**.

### what does the list show?

the current list provides employee ID/name, department, beginning-balance employment dates, gross compensation, non-taxable components, taxable components, totals, and tax withheld. Use search and sort to locate an employee.

### how do I import beginning balances?

1. select **Upload Employee List**.
2. download a fresh **BB Download Template** and check the version shown on the page before completing it.
3. preserve every column header and remove all sample and empty rows.
4. complete the required Employee ID and employment-from/to dates.
5. enter numeric amounts only in the corresponding compensation and tax columns.
6. save the file as CSV.
7. choose the file and select **upload file**.
8. review the result for every row before relying on the list.

### important field groups

* gross compensation from the present employer;
* basic salary and statutory-minimum-wage amounts;
* 13th Month and other benefits;
* de minimis benefits;
* employee contribution/union-dues amounts;
* other salary and compensation amounts;
* taxable amounts in excess of applicable exemptions; and
* tax withheld.

### rules and warnings

* Beginning Balance employment dates describe the period represented by the imported totals; they are not a substitute for the employee's actual Ashima hire date.
* the import introduction may refer to overtime pay rules even though the page, template, fields, and destination are Beginning Balance. Follow the Beginning Balance fields and template; do not use the overtime wording as the data rule.
* after import, compare the employee row, year-end/tax reports, and relevant payroll outputs to the approved source.
* use Previous 2316 for prior-employer certificate information; do not merge it into present-employer beginning balances without an approved accounting/tax basis.
