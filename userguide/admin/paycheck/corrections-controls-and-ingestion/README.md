# corrections, controls, and ingestion

Use this area when payroll needs a correction or imported input, when payroll-affecting changes must be paused, or when a correction belongs to a payroll that has already moved beyond normal open review.

Choose the method that matches the timing and source of the change:

| need                                                                                 | use                              |
| ------------------------------------------------------------------------------------ | -------------------------------- |
| correct the current open pay run directly                                            | Paycheck adjustment or ingestion |
| import supported payroll inputs from a prepared file                                 | ingestion CSV import             |
| pause payroll-affecting employee, manager, or administrator work during final review | Payroll Lock                     |
| process an eligible late correction after the original payroll moved forward         | Post Payroll Adjustment          |
| establish historical starting values                                                 | beginning balances               |
| move an employee to another payroll group through the supported payroll process      | payroll-group transfer           |

After adding, editing, importing, or removing a payroll input, return to the owning pay run, recalculate when required, and verify the result in employee pay details and the Payroll Masterlist.
