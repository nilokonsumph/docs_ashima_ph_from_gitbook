# review, download, and remove ingestion entries

use the ingestion list for the selected source to search employees, review saved categories and items, download the current list, and open an entry for correction when supported.

before removing an entry, confirm that it belongs to the intended source and has not been relied on for approved or closed work. after a permitted edit or removal, recalculate the open source and confirm the employee totals. closed or historical work requires the owning correction workflow rather than silent source deletion.
