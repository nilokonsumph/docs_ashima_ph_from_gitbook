# ingestion terms

| term         | meaning                                                                         |
| ------------ | ------------------------------------------------------------------------------- |
| source type  | the owning calculation or payment workflow receiving the ingestion entry        |
| source ID    | the selected pay run, termination, year-end, 13th Month, or disbursement record |
| pay category | the calculation family used to classify the ingestion entry                     |
| pay item     | the configured or built-in item selected within a pay category                  |
| tax status   | the taxable, non-taxable, or fixed treatment allowed by the selected item       |
