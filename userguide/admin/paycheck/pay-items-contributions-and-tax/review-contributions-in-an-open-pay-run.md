# review contributions in an open pay run

1. open the draft pay run and select the employee.
2. review the contribution base and each employee and employer contribution.
3. compare the result with the saved company rule, employee choice, eligible earnings, and contribution schedule.
4. correct the owning setting, employee record, earning, or adjustment.
5. recalculate the pay run and confirm the corrected contribution before approval.

an adjustment or ingestion row can change the source amount used by payroll. confirm the category and tax or contribution meaning instead of relying on the row label alone.
