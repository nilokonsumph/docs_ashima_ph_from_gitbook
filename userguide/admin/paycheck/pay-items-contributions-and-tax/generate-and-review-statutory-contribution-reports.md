# generate and review statutory contribution reports

**navigation:** go to **Reports**, then select the applicable SSS, PhilHealth, or HDMF report.

1. select the reporting period and other required source filters.
2. generate or save the report.
3. open its detail or preview.
4. verify the company registration, employee identifiers, employee count, contribution totals, and payment-file format where available.
5. download the required output only after the review is complete.

the generated result represents the saved company, employee, and completed payroll records within the selected period and scope.

if a report is incomplete, correct the source company, employee, or payroll record and regenerate it. editing a downloaded report does not correct Ashima's source records.
