# handle a historical PHIC adjustment record

the preserved source described a dated PhilHealth differential facility for the 2022 transition under PhilHealth Circular No. 2020-0005. treat this as historical guidance for existing records, not as a current general instruction to create a new 2022 amortization.

where the facility remains available for an existing company record:

1. download the current PHIC adjustment template from the page.
2. identify the employee, supported target payroll date, and approved adjustment amount.
3. use one row for a lump-sum deduction or separate dated rows for a supported staggered schedule.
4. review every row before upload.
5. upload the corrected template and confirm the resulting list.
6. recalculate the eligible open pay run and review **Deductions / Loans → PhilHealth Adjustment**.

{% hint style="warning" %}
**warning:** the preserved facility did not provide an ordinary delete action. a corrected re-upload overwrote the previous data. confirm that this behavior and the legal basis still apply before using the historical facility for a current correction.
{% endhint %}
