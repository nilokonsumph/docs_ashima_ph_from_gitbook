# contribution and compliance terms

| term                  | meaning                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------- |
| contribution base     | the supported payroll amounts used to calculate a statutory contribution                                       |
| contribution schedule | the configured pay-run timing for deducting a contribution                                                     |
| employee portion      | the amount deducted from the employee where applicable                                                         |
| employer portion      | the company contribution recorded with the employee result                                                     |
| PHIC                  | PhilHealth contribution label used in Ashima                                                                   |
| statutory report      | an Ashima output prepared from saved company, employee, and payroll records for the selected agency and period |
