# salary increases and retroactive pay

Use this area when an employee's salary changes or when payroll must calculate the supported effect of an increase from an earlier effective date.

Choose the task by scope:

* use the individual salary-increase process for one employee;
* use the bulk update when several supported employee salaries change together;
* review salary-increase details to verify the effective date, old and new salary, and calculation result;
* use retroactive pay when an eligible prior-period difference must be recalculated under the supported retroactive-pay rules.

Review effective dates and overlapping records carefully. A later entry does not automatically prove that an earlier increase or retroactive result should be replaced. Reconcile every resulting amount before payroll approval.
