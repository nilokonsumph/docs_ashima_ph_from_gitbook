# download disbursement outputs

Download disbursement outputs using the status-gated actions shown in the current disbursement preview.

{% hint style="warning" %}
**important:** Bank and cash files can be used to release payments. Confirm the disbursement status, total, employee bank information, and selected file type before using a downloaded file.
{% endhint %}

\*\*navigation:\*\* go to \*\*Disbursement\*\*, open the applicable record, then use the available download actions.

## what outputs may be available?

* disbursement report in Excel or CSV
* **Bank File** for a configured bank or bank format
* **Cash File**
* **Generate Payslip**

the exact bank choices depend on the company's configured bank options.

**Bank File**, **Cash File**, and **Generate Payslip** are status-gated actions in the current preview. **Generate Payslip** is available only for a **Closed** disbursement. Closing is the completion point inside Ashima; external file acceptance and actual fund release remain separate company processes.

## how do you prepare an output?

1. open the approved or final disbursement.
2. confirm the disbursement date, voucher number, and total.
3. confirm that the last recalculation is current.
4. review the employee rows one last time.
5. select the required report, bank, cash, or payslip action.
6. choose the correct file format when more than one is available.
7. Check the downloaded file before submitting it to a bank or using it for payment.

## why might a bank option be missing?

Bank output choices depend on company bank setup and the formats supported for that bank. Use only the option intended for your company's account and payment process.

also confirm that the disbursement is **Closed** and that the employee payment information supports the selected output. Correct bank details at the employee source before generating a replacement file.

## what should i retain for audit?

retain the closed disbursement reference, voucher number, reviewed totals, selected output type, and the approved file according to company policy. A generated or downloaded file does not by itself prove bank acceptance or employee receipt.

## confirm the output result

a successful action produces the selected report, bank file, cash file, or payslip output for the closed disbursement. open the downloaded file and confirm its type, date, employee count, total, bank format, and representative employee values before releasing it outside Ashima.
