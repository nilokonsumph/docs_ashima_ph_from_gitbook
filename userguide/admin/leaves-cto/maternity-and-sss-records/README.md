# maintain maternity and SSS source records

Use this area to calculate and maintain maternity benefits and to provide supported previous SSS contribution information when Ashima does not already contain the required historical source.

Maternity combines application information, contribution history, benefit calculation, approval, and payroll treatment. Verify the source months and uploaded evidence before relying on the calculated amount.
