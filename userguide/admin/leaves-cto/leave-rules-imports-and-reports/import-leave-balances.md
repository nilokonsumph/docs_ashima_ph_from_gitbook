# import leave balances

## import leave balances

use **Upload Manager → Leave** for employees and leave types that can be matched to current assignments. use **Unassigned Leave** only for the supported intake path where an assignment is not already present.

### before you upload

download the current template, retain its headers, confirm the company, employee identifiers, leave types, dates, and balances, and keep a copy of the source file used for the run.

### how do i import balances?

1. open the applicable leave upload page.
2. download and complete the current template.
3. upload the file.
4. review the file-level and row-level validation results.
5. correct rejected rows without changing accepted source data unnecessarily.
6. submit the valid rows through the supported confirmation step.
7. open affected employee balances and transaction ledgers to verify the result.

Ashima checks the company, employee, leave type, eligibility, dates, balances, and row order. some rows can be rejected while other rows are valid. review the downloadable errors, correct only the rejected rows, and upload them again. after completion, confirm each affected employee's leave assignment, balance, and transaction ledger.
