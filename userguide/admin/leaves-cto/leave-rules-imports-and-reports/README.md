# maintain leave rules, imports, and outputs

Use this area to connect leave configuration with balance maintenance, expiry, carryover, conversion, forfeiture, imports, and report outputs.

Settings owns the complete rule configuration. Leave tasks explain the operational consequence, while Reports owns generation of the resulting outputs. After an import or authorized rule change, verify affected balances and any required report or payroll result.
