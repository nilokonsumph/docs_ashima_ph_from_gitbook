# manage leave balances, transfers, and CTO

Use this area to assign or correct balances, transfer supported leave credits, and administer compensatory time off.

Confirm whether the record is leave, CTO, or maternity before changing it. Each has a different source, eligibility rule, balance effect, and downstream payroll treatment.
