# trace leave transactions

## trace leave transactions

use the transaction ledger to trace how an employee's leave credits were added, reserved, approved, used, returned, adjusted, transferred, or expired.

**Navigation:**\
go to **Leaves → Leave Balance**, open the employee, then select **View Transaction** for the required leave type.

### how do i read a balance movement?

each row represents a balance movement. use the date, transaction type, amount, reference, and resulting balance to follow the sequence of events.

common movements include:

* earned or opening credits
* leave application or reservation
* approval and use
* rejection or cancellation return
* manual adjustment
* transfer
* expiry
* CTO conversion, when the selected type is CTO

### how do i trace a balance question?

1. select the employee and leave type.
2. open **Transaction Ledger**.
3. start with the most relevant application, conversion, adjustment, or expiry row.
4. read the description, source, amount, and resulting balance shown in the ledger. Compare visible references and dates across related movements.
5. select **Back to Leave Balance Details** to return to the employee's balance.

### how do i investigate a leave movement?

read the movement details shown in the ledger row. The description and source help identify why credits were added or used; the amount and resulting balance show the effect. Compare related rows to trace a reservation, approval, cancellation, return, transfer, or expiry. A reference or expiry date may appear when it applies to that movement.

### how do i download the ledger?

select **XLS** or **CSV** on the ledger to download the selected employee and leave type's movements. Check the employee and leave type before sharing or relying on the file.
