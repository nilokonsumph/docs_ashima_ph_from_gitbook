# review and manage leave requests

Use this area to see current and upcoming leave, file leave for an employee, review or cancel a request, and trace the resulting leave transaction.

The calendar supports operational visibility; the request and history records remain the evidence for status, approval, and cancellation. Verify the employee, leave type, dates, duration, and resulting balance before completing a change.
