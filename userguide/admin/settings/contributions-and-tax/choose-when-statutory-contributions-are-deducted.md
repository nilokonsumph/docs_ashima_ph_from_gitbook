# choose when statutory contributions are deducted

use **Contribution Schedule** to choose the payroll occurrence in which Ashima deducts SSS, HDMF, modified HDMF, and PhilHealth contributions. this controls timing within the month; it does not define the statutory table or contribution amount.

**navigation:** go to **Settings → Paycheck → Contributions → Contribution Schedule**.

## choose a schedule for each contribution

the current page requires a schedule for each of these rows:

* SSS;
* HDMF;
* modified HDMF; and
* PhilHealth.

available choices are **first payroll of the month**, **second payroll of the month**, and **every payroll**. **last payroll of the month** is also offered when the company has a **Fortnightly** pay schedule.

the description beside each row is maintained separately from the schedule choice. use it to make the company rule recognizable to reviewers.

## update the schedule

1. select **Edit**.
2. choose a schedule for all four contribution rows.
3. review the descriptions.
4. select **Update**.
5. confirm that the saved choices reload on the page.
6. recalculate a representative open pay run and verify that each contribution appears in the intended payroll occurrence.

{% hint style="warning" %}
**important:** this page controls when the deduction is taken. use **Contribution Rules** for eligibility or calculation-rule settings and the applicable statutory table guidance for table values.
{% endhint %}
