# configure contributions and withholding tax

Use this area to define supported contribution timing, company contribution rules, and withholding-tax schedules or options.

Statutory reference tables are governed data rather than ordinary company preferences. Separate the governed rate or threshold from the company-selectable timing or method, and verify the resulting employee and employer amounts in an eligible open payroll.
