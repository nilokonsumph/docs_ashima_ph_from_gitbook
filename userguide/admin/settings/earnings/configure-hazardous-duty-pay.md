# configure hazardous duty pay

use **Hazardous Pay** to define a reusable hazardous-duty earning and the employees for whom it can apply. the definition controls its frequency basis, value method, eligibility filters, tax treatment, supporting requirements, and how absences or leave affect entitlement.

**navigation:** go to **Settings → Paycheck → Earnings → Hazardous Pay**.

## choose the earning basis

| setting              | choices shown by the current page                | effect                                                                         |
| -------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| frequency            | **Per Workday** or **Hours Worked**              | determines whether the earning is based on eligible workdays or eligible hours |
| hours window         | start and end time                               | limits the hours considered when the frequency uses hours worked               |
| value method         | **Daily Rate Percentage** or **Specific Amount** | uses either the saved percentage basis or the saved amount basis               |
| applicable employees | rank, employment status, and position selections | limits which employees can qualify for the item                                |
| tax                  | **Exempt** or **Not Exempt**                     | records the item's tax treatment used by the payroll path                      |
| entitlement          | absence and leave switches                       | controls whether those conditions affect entitlement under the saved rule      |

## create a hazardous-pay item

1. select **add hazard pay**.
2. enter a clear item name.
3. choose **Per Workday** or **Hours Worked**. when using hours, enter the supported start and end time.
4. choose **Daily Rate Percentage** or **Specific Amount**, then enter the corresponding value.
5. select the applicable ranks, employment statuses, and positions. review whether **All** is appropriate before saving.
6. select **Exempt** or **Not Exempt** based on the company's verified payroll treatment.
7. add any requirements and an administrator note.
8. set the absence and leave entitlement switches.
9. save and verify the item in the list.

open a saved item to review or edit it. use the list selection and delete action to retire an item; Ashima retires the item instead of erasing its historical record.

{% hint style="warning" %}
**warning:** confirm the company's policy and applicable rule before selecting the tax treatment or amount. recalculate an affected open pay run after a change.
{% endhint %}
