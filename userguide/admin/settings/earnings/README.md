# configure earnings

Use this area to define reusable earning types and the rules that determine their supported amount, tax treatment, eligibility, frequency, limits, or payroll behavior.

Creating a company item does not automatically assign it to every employee. Confirm the employee assignment and recalculate the applicable open payroll before relying on the result.
