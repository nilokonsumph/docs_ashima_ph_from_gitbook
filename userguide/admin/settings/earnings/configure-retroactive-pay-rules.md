# configure retroactive-pay rules

## Retroactive Settings

use this page to control whether retroactive-pay processing is enabled for the company.

**navigation:** go to **Settings → Pay Check → Earnings → Retroactive Settings**

## review saved retroactive-pay rules records

the page displays the company retroactive-pay main setting and its current enabled state.

## manage retroactive-pay rules

you can turn retroactive-pay processing on or off at company level.

## verify the saved retroactive-pay rules

the system updates the company retroactive-pay main setting, and payroll can then allow or block retroactive-pay use based on that status.

## apply the retroactive-pay rules

* this page controls the company-level enablement of retroactive pay, not the employee-level assignment of a retroactive-pay amount
* if retroactive pay is disabled here, payroll users should not expect the related payroll flow to behave as available later in **Pay Check**

## update and verify availability

1. open **Settings → Paycheck → Earnings → Retroactive Settings**.
2. turn the company option on or off as intended.
3. save and reopen the page to verify the state.
4. open the eligible retroactive-pay workflow and confirm its availability.
5. if availability is wrong, restore the prior setting and review the user's privilege, employee eligibility, and payroll state before retrying.

the expected result is that the retroactive-pay workflow is available only when the company setting, user privilege, employee eligibility, and payroll state all permit it.
