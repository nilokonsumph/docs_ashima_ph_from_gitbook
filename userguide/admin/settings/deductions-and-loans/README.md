# configure deductions and loans

Use this area to choose the correct deduction family and define supported government loan, third-party loan, insurance, or other-deduction behavior.

Company configuration defines the available item; employee assignment and payroll conditions determine the amount deducted. Verify both layers before correcting a payroll result.
