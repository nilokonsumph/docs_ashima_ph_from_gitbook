# configure payroll structure and rates

Use this area to define the calendar and rate basis used by payroll and to organize employees into payroll groups with the correct pay schedule.

These values can change derived daily or hourly rates, premium treatment, eligible pay periods, and the employees included together in a pay run. Recalculate and verify a safe open-payroll example after an authorized change.
