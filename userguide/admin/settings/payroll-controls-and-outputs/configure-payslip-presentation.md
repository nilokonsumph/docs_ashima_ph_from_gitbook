# configure payslip presentation

use **Settings → Paycheck → Payslip Template** to configure the fields shown in current payslip output.

## what can i configure?

choose displayed payslip fields for **Default**, **By Two / Page**, and **By Four / Page** output. You can also configure company details, contact email, and a custom footnote.

## what should i check before saving?

Compact earnings selections are limited to 15 fields for **By Two / Page** and 25 fields for **By Four / Page**. Review the displayed selections and validation before saving.

## update and verify the template

**Navigation:** go to **Settings → Paycheck → Payslip Template**.

1. choose the output layout.
2. select the fields that should appear within the supported layout limit.
3. update company details, contact email, or footnote when required.
4. save the template.
5. generate a test payslip and verify the field labels, values, order, wrapping, and company information. the expected result is a readable file containing only the supported selected fields.
6. if the output is incomplete or unreadable, correct the selection and generate a new test output; changing the template does not rewrite a previously delivered file.
