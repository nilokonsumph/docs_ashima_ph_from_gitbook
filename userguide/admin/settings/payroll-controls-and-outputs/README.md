# configure payroll controls and outputs

Use this area for payment-file options, pay-run warnings, Post Payroll Adjustment availability, and payslip presentation.

Separate calculation controls from presentation and delivery controls. For example, hiding a payslip line does not remove the amount from payroll, and configuring a bank layout does not assign an employee bank account or change net pay.
