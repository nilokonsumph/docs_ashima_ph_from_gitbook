# definition of terms

| term                    | meaning                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------- |
| default                 | the value or route used when no supported, more specific selection overrides it                                     |
| effective timing        | when a saved setting begins to influence new or recalculated work                                                   |
| employee-scoped setting | a setting or assignment that applies to selected employees rather than the whole company                            |
| inheritance             | reuse of a company, group, rank, item, or employment-type value by a more specific record                           |
| open record             | a draft, pending, or otherwise editable record that may still respond to an eligible source change or recalculation |
| override                | a supported, more specific value that replaces an inherited or default value for its documented scope               |
| pay schedule            | the recurring payroll frequency and dated periods used to prepare payroll                                           |
| payroll calendar        | the dated payroll periods and pay dates generated from a pay schedule                                               |
| payroll group           | a grouping that supplies payroll defaults and employee scope for supported payroll work                             |
| recalculation           | regeneration of a result from the eligible current source records and settings                                      |
| reference table         | dated or statutory information that the product uses or displays; it is not necessarily a company-editable rule     |
| setting                 | a saved company, group, employee, item, or process choice that controls supported product behavior                  |
| Workflow                | the configured approval levels and approvers for a supported process                                                |
