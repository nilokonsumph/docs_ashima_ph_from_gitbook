# configure time entry, Hours, Shifts, and holidays

Use this area to define how employees record time and how Ashima interprets the resulting logs against shifts, breaks, thresholds, rest days, and holidays.

Configure the source rules before assigning employee methods or schedules. Validate a safe example from time entry through Timesheet, Hours review, and payroll when a rule can change paid time or premium treatment.
