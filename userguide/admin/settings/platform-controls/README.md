# configure uploads, Workflows, and manager access

Use this area for platform controls that change how data enters Ashima, how requests are routed, or what managers and Admin My Team users can see and do.

These controls do not automatically change payroll calculations. They can change available inputs, approvers, employee scope, and supported actions that later affect a module workflow.
