# definition of terms

| term                  | meaning                                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| compensation details  | the employee's payroll group, pay basis, base pay, statutory choices, payment information, and entitlements                                |
| confidential employee | an employee whose record and payroll-group handling follow the configured confidential-access rules                                        |
| effective date        | the date from which an eligible employment or compensation change applies                                                                  |
| Employee 201          | the consolidated employee record and export used to review personal, employment, government, and payroll-linked information                |
| employee visibility   | the company, confidentiality, and manager or administrator scope that controls which employee records the signed-in user can open          |
| employment details    | the employee's job, department, employment type, rank, location, cost center, reports-to relationship, government IDs, and related history |
| entitlement           | an employee-level choice that permits supported pay, leave, contribution, or premium treatment                                             |
| payroll group         | the employee grouping that supplies the supported pay schedule and payroll defaults                                                        |
| reports to            | the employee relationship used by the organization chart and direct-reports visibility                                                     |
| 2FA                   | two-factor authentication; an additional login verification step using a compatible authenticator and recovery codes                       |
| Workflow assignment   | the approval route assigned to a supported employee request type                                                                           |
