# manage portal, time-entry, and security access

Use this area to control how an employee accesses the portal, which supported time-entry method is assigned, and how two-factor authentication is managed.

Portal credentials, time-entry eligibility, network or device restrictions, and 2FA are separate controls. Verify the result using the employee's intended access method without broadening unrelated permissions.
