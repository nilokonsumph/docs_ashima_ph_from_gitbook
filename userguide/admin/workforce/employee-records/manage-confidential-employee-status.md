# manage confidential employee status

use the Confidential screen to review and update an employee's confidential status and, when the screen requests it, the payroll-group transfer.

{% hint style="warning" %}
**warning:** confirm the receiving payroll group and the displayed confidential-status change before saving.
{% endhint %}

\*\*navigation:\*\* open the employee record, then select \*\*Confidential\*\*.

## what does confidential access control?

the current screen shows the employee's confidential status and the payroll-group transfer requested for the change. It is separate from ordinary page privileges.

## how do i update confidential status?

1. open the employee record.
2. select **Confidential**.
3. click **Edit** when required.
4. update the confidential setting.
5. select the required payroll-group transfer when the form requests it.
6. review the warning.
7. click **Save**.

## what happens after saving?

review the saved confidential status and any required payroll-group transfer. This page does not define visibility coverage outside the current confidential-employee screen.

## correct an unintended confidentiality change

if the saved status or payroll group is wrong, stop before running payroll. reopen the employee, restore the supported confidentiality choice and matching payroll group, then confirm employee visibility and the next eligible pay-run group. if an open payroll already includes the employee, resolve the group or exclusion state and recalculate before approval.
