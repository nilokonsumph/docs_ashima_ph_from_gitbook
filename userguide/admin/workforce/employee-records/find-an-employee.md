# find an employee

use the employee directory to find an employee, review the profile summary, and open the employee record for detailed maintenance.

**navigation:** go to **Workforce → Employee Directory**.

## review directory results

the directory displays employee cards within your access scope. It provides employee-name search, an **All** or A–Z surname selector, and a **More** action for each employee.

the directory is a lookup page. Edit actions belong to the employee detail pages rather than the main listing.

## how do i find an employee?

1. enter the employee name in search, or select **All** or the first letter of the employee's surname.
2. review the matching employee cards.
3. click **More** for the employee you need.

## what happens after i open an employee?

the available destination depends on the employee card and your privileges. Employee detail pages can provide related links such as **Leaves**, **CTO**, **Shifts**, **My Team Access**, and **Documents**.
