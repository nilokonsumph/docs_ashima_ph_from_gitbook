# review employee Workflow approvers

use the employee's Workflow information to confirm which approval groups apply to Timesheet, Leave, Overtime, Shift, and Maternity requests.

1. open the employee record and review **Workflow Approvers** or the applicable Workflow assignment area.
2. confirm each mapped request type and approval group.
3. compare the assignment with the company or employee-scoped Workflow in Settings.
4. submit a controlled request when verification is required and confirm the first approver in Todo.

changing the employee assignment does not approve a pending request or guarantee that an inactive approver was replaced. review pending work before changing a route.
