# start here: manage employee records

use Workforce to create an employee, maintain the employee's personal, employment, compensation, access, and status records, and supply the employee information used by Shifts, Hours, Leaves, Paycheck, Workflow, Reports, Documents, and Disbursement.

## choose the task you need

| goal                                                       | Workforce task                                                              | connected guide                                                                              |
| ---------------------------------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| create one employee or import several                      | onboard employees                                                           | Settings supplies the lists and payroll defaults used during onboarding                      |
| find and review an employee                                | find an employee; review Employee 201                                       | employee visibility and confidentiality determine which records you can open                 |
| maintain identity, employment, and reporting relationships | maintain personal details; maintain employment details                      | Settings owns locations, departments, positions, employment types, ranks, and payroll groups |
| maintain pay and entitlements                              | set up employee compensation; review compensation history                   | [Paycheck](../paycheck/) owns payroll calculation and review                                 |
| maintain attendance eligibility                            | configure employee time entry                                               | [Hours](../hours/) owns captured-time review                                                 |
| assign loans and deductions                                | assign employee loans and deductions                                        | Settings owns reusable item definitions; Paycheck owns the payroll result                    |
| update access or separation state                          | manage confidential status; change employee status; manage account security | [Control Center](../control-center/) owns administrator company and page access              |
| verify reporting lines and approvals                       | review the organization chart; review Workflow approvers                    | [To Do and Workflow](../todo-workflow/) owns approval routing and decisions                  |

## understand the employee-record sequence

1. create or locate the employee.
2. confirm personal identity and contact information.
3. assign employment structure, status, reporting manager, and government identifiers.
4. assign payroll group, pay basis, base pay, statutory choices, and entitlements.
5. assign the correct shift, leave, time-entry, Workflow, earning, deduction, and access records.
6. verify the employee in Workforce and one representative downstream workflow before the first payroll.

{% hint style="warning" %}
**warning:** changes to payroll group, base pay, status, confidentiality, time-entry requirements, contribution choices, or entitlements can change payroll eligibility or results. review open payroll and effective timing before saving, then recalculate eligible open work when required.
{% endhint %}
