# review payroll groups and their employees

use **Workforce → Payroll Group** to check which employees belong to each payroll group and review the group's calculation type, pay schedule, and assigned work schedule.

a payroll group brings together employees who use the group's payroll setup. to create or change the company definition, use [pay schedules and payroll groups in Settings](../../settings/payroll-structure-and-rates/configure-pay-schedules-and-payroll-groups.md). to review an employee's individual assignment, use [employee compensation](set-up-employee-compensation.md).

## how do i find a payroll group?

1. open **Workforce → Payroll Group**.
2. type a group name and press **Enter**, or select a suggested name to find that exact group. use **X** to clear the search.
3. review the group name, employee count, calculation type, pay schedule, and assigned work schedule. use pagination for additional groups.
4. open a group row to review its employees.

## how do i review employees in a group?

1. confirm the group name, then review employee ID, name, position, department, reports-to, and status.
2. search for an employee or select an exact match from the suggestions. if you change the text after selecting a person, select the intended person again or apply the new text search.
3. clear the search to return to the first page, or move through the matching employee pages.
4. use the payroll-group breadcrumb to return to the group list.

if a group is unavailable or an access message appears, check the selected company and ask your account administrator to review your access.

## how do i download the list?

choose **XLS** or **CSV** on the group list or inside the selected group. the group-list download contains matching groups; the group-detail download contains matching employees in that group.

{% hint style="info" %}
review the search fields before downloading. these downloads use the current search values across result pages, so they can differ from the last list you loaded. apply the intended search first, then check the downloaded file's coverage.
{% endhint %}
