# maintain compensation and payroll assignments

Use this area for employee-specific compensation history and payroll assignments. Company definitions and rules remain in Settings; Workforce records determine which employee receives or uses the configured item.

After changing an assignment that affects an eligible open payroll, recalculate and verify the employee result in Paycheck.
