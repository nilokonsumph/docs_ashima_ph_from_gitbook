# start here: manage account and administrator access

open Control Center when you need to manage account details, administrator access, businesses, security, or plan information.

**navigation:** header account menu → **Control Center**

## open the right account

1. sign in to the intended Admin account and complete any required verification or two-factor authentication.
2. open the header account menu and choose **Control Center**. it opens Business Profile.
3. check the account and business context before choosing a task. a menu entry does not guarantee permission to perform every action on that page.

## choose an available task

use this table to choose the Control Center destination for the task you need to complete.

| task                              | where to go                                                         | availability to check                                                                                 |
| --------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| personal and billing information  | **Account Profile**                                                 | company/billing fields have additional visibility conditions.                                         |
| choose or manage a company        | **Business**                                                        | the company list and create/delete controls depend on access.                                         |
| support access                    | **Support**                                                         | see the existing utilities guidance for the distinction between support resources and Support Access. |
| plan and capacity information     | **Add Ins**                                                         | opens Plan Information, not an installation or purchase flow.                                         |
| administrator roles               | **Teams** for owners; **Privilege** for designated administrators   | these labels open the same role-management destination.                                               |
| confidentiality rules             | **Rules** for owners; **Admin Rules** for designated administrators | these labels open the same rules destination.                                                         |
| password policy or employee scope | **Security** or **Admin My Team Access**                            | shown in owner/designated-administrator menus.                                                        |
| designated administrator          | **Designated Admin**                                                | owner-menu entry.                                                                                     |

use the task pages below for roles, designated administrators, security, businesses, account details, and plan information. API credentials are managed in **Settings → Notification Manager → API Settings**; appearance is a shared-header preference, not a Control Center sidebar page.

## keep access boundaries separate

an ordinary administrator may not see the same companies or menu as an owner or designated administrator. check the relevant page's prerequisites; do not assume a direct link bypasses them. named roles, confidentiality, employee scope, and workflow approval are different controls.
