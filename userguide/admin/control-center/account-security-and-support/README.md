# manage account security and support

Use this area to maintain account-wide password controls, temporary Ashima Support Access, and API credentials.

These controls can affect every business under the account. Review the intended scope, authorized user, expiry or revocation behavior, and recovery path before saving or removing access.

## tasks in this area

* [configure account password and lock policies](configure-account-password-and-lock-policies.md)
* [manage Ashima Support Access](manage-ashima-support-access.md)
* [generate or remove API credentials](generate-or-remove-api-credentials.md)
