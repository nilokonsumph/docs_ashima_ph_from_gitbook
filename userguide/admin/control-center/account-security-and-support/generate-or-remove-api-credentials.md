# generate or remove API credentials

use API Settings to view, generate, or remove credentials for the intended account and company.

**navigation:** **Settings → Notification Manager → API Settings**

## check eligibility and existing credentials

API Settings is not a Control Center sidebar entry. the **api(s) > api generation settings** menu label controls visibility, but account and company eligibility are separate. employee and support contexts are not eligible, and the company must be valid.

the list contains active credentials for the current account/company. check that context before taking action. treat API ids and keys as sensitive; do not put real credentials in shared manual examples or screenshots.

## generate when the list is empty

**Generate Key** is disabled while the credential list is nonempty. when it is available, choose it and complete the confirmation. generation creates or reuses the associated API user and shows the **API ID** and **API Key** in the list.

review the generated credential and any error feedback. store the credential securely and do not include it in screenshots or shared documents.

## remove selected credentials

> **warning:** confirm the intended account, company, and selected credential. update any integration that still uses the credential.

select the intended rows, choose **Delete**, complete the confirmation, and review the result. deleting a credential can stop connected integrations from working. confirm the selected credential and update any affected integration before deleting it.
