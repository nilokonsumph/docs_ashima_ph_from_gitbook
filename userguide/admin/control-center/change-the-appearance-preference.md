# change the appearance preference

use the shared header's appearance control to switch between the default and dark appearance.

**navigation:** shared header → default/dark appearance control

## change your preference

choose the desired default or dark appearance. after a successful update, the browser uses the selected appearance and the preference is saved for the account for subsequent loading.

check the visible result before treating the change as successful.

## keep the scope clear

this preference changes the signed-in account's appearance in the shared header and Control Center. it does not change the company-wide appearance for other users.
