# definition of terms

* **account owner** — the top-level account user who can manage businesses and owner-only Control Center functions.
* **administrator** — an account that uses the admin portal under assigned account, company, role, and access conditions.
* **designated administrator** — an administrator delegated broader account responsibilities by the owner. this assignment uses a separate access path from an ordinary administrator.
* **role label** — a short name used to identify an administrator's responsibilities. it does not determine which pages the administrator can access.
* **permission label** — a page or action entry displayed under **Available Roles** or **Selected Roles**. these selections can be customized for any administrator regardless of the role label.
* **company selection** — the companies included in an ordinary administrator's access arrangement.
* **confidentiality rule** — the **Rules / Admin Rules** choice that limits the administrator to confidential employees, non-confidential employees, or both.
* **Admin My Team Access** — the switch that enables or disables the my team entry path for an eligible administrator.
* **Manager Privileges** — the employee-level configuration that controls the manager's visible population and permitted manager actions.
* **Workflow** — the approval configuration that identifies approvers and approval order.
* **invitation status** — the state of administrator account setup or invitation completion.
* **enabled state** — whether an administrator account is active for access; it is separate from invitation and permissions.
* **Support Access** — temporary access granted to Ashima support for account assistance.
* **read only** — the narrower Support Access type intended for inspection.
* **full access** — the broader Support Access type.
* **available slots** — the remaining account capacity shown on **Plan Information** after counted employees and administrators are considered.
* **Audit Trail** — a history of supported setting changes, including the actor, target, time, and before-and-after state when recorded.
* **API credential** — an **API ID** and **API Key** generated for an eligible account and company integration.
