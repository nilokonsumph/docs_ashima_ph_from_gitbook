# resolve missing company, page, or action access

check the setting that controls the missing access. the label under **Roles** does not determine which companies, pages, or actions the administrator can use.

## what should i check?

1. confirm that the administrator account is enabled and that the invitation has been completed.
2. for a missing business, check that it is selected under **List of Companies**.
3. for a missing page or action, check the administrator's selections under **Available Roles** and **Selected Roles**.
4. for missing employee records, check **Rules / Admin Rules**, **Admin My Team Access**, and any applicable Manager Privileges.
5. for a missing approval task, check the applicable Workflow assignment.
6. save the correction, reload the administrator details, and verify the result using the intended account and company.

change only the setting connected to the missing access. company selection, page permissions, employee visibility, and approval assignments are separate controls.
