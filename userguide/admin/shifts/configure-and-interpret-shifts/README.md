# configure and interpret shifts

Use this area to understand the settings that control Shifts and to configure reusable shift definitions, schedule rules, thresholds, breaks, rest days, open shifts, holiday context, and cross-day premium treatment.

Settings owns the complete configuration procedure. The Shift guide explains how the selected rule affects scheduling, timesheet interpretation, and payroll context. Validate consequential changes with a safe dated assignment after the affected shift has ended.
