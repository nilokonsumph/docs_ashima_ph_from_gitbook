# definition of terms

| term                       | meaning                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **shift template**         | reusable schedule definition created in shifts planning                                                       |
| **shift assignment**       | schedule applied to an employee for specific dates                                                            |
| **default work schedule**  | schedule inherited from the employee's payroll group when no date-specific assignment replaces it             |
| **Mark as Rest Day**       | explicit assignment that treats selected dates as non-working days                                            |
| **Uniform schedule**       | fixed workday pattern used by regular, compressed, night, and rest day templates                              |
| **Flexi Time**             | schedule based on required hours and flexible timing rules                                                    |
| **Open Shift**             | schedule without one fixed daily clock-in and clock-out pattern                                               |
| **overnight shift**        | schedule whose end time falls on the next calendar day                                                        |
| **archive**                | removes a template from the active selection list while retaining it for restoration and historical reference |
| **holiday location scope** | locations whose employees are affected by a company holiday record                                            |
