# plan and assign shifts

Use this area to review the schedule calendar, assign shifts individually or in bulk, replace an existing dated assignment, and archive shift definitions that are no longer used.

Every employee retains schedule context through the applicable default or dated assignment. Plan and assign shifts before the workday starts so Timesheet and Hours can interpret punches against the intended schedule.
