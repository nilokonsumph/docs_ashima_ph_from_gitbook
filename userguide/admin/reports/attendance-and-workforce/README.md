# generate attendance and Workforce reports

Use this area to select attendance, paid-hours, and Workforce outputs and reconcile them with the source employee, shift, and timesheet records.

Use the report that answers the question, then trace any difference back to its owning source rather than treating similar totals from different reports as interchangeable.
