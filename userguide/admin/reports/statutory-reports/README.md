# generate statutory reports

Use this area to choose and generate SSS, PhilHealth, HDMF, BIR, and withholding-tax outputs.

Confirm the reporting period, employee population, completed payroll state, and applicable statutory reference before relying on an output. A generated file reflects its source records; it does not correct them.
