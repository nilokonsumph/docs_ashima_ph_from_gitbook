# Dashboard

Use the admin dashboard to see current payroll, attendance, leave, holiday, and workforce reminders in one place.

Dashboard cards are summaries. Open the related page when you need to investigate or correct a record.

**navigation:**\
Go to **Dashboard**.

### what can the dashboard show?

Depending on company setup and your access, the dashboard may show:

* Clocked-in employees
* Early birds
* No show
* Tardy employees
* Undertime
* Employees out on leave
* Next payroll
* Payroll breakdown
* Upcoming holiday
* Birthdays and work anniversaries
* Company announcements

### how should you use the attendance cards?

1. Review cards with unexpected counts.
2. Open the related Hours page from the card when available.
3. Check the employee's time logs and assigned shift.
4. Confirm whether a pending adjustment or approval explains the result.
5. Correct the source record rather than treating the dashboard count as the final record.

### why can two administrators see different results?

Dashboard visibility can depend on role, assigned privileges, manager scope, and confidential-employee access. A hidden card or employee does not always mean the underlying record is missing.

### when do dashboard values change?

Values update when their source records change. Examples include new time logs, approved leave, updated payroll dates, holidays, employee details, and announcements.
