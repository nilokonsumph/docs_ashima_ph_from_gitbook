# Compensatory time off

use compensatory time off to convert eligible approved work into time-off credits that an assigned employee may use later.

**Navigation:**\
go to **Settings → Leaves → CTO** for setup. Use **Leaves → CTO Balance** to review assigned cto types and credits, then select **CTO Conversions** to review approved source work available for conversion.

## how is cto different from ordinary leave?

cto is managed through the Leave module, but it is not the same as ordinary leave. Ordinary leave is usually earned or accrued from a policy. Cto is a credit bank created from approved source work, such as overtime, rest-day work, or holiday work.

because cto uses the Leave module, some screens still use leave-related labels. The employee must first receive the relevant cto assignment, and the source work must be eligible and approved before conversion.

the current conversion page uses **Ready**, **Converted**, **Select All Eligible**, and **Wrap Selected**. The page refers to converting approved source rows into cto credits as wrapping.

use the dedicated [compensatory time off guide](https://docs.ashima.ph/admin/leave/compensatory-time-off) for setup, assignment, conversion, balance pools, expiry, applications, cancellation, the ledger, and the paycheck bridge.
