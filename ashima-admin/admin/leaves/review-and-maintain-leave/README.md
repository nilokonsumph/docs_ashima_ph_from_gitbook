# Review and maintain leave

use this section to review leave history, calendar activity, balances, employee assignments, applications, and cancellations.

**Navigation:**\
go to **Leaves → Review and maintain leave**.

### recommended order

1. start with **Leave overview and history**.
2. use **Leave calendar** for date-based planning.
3. open **Leave balances** for employee credits and detail.
4. use **Assign leave or CTO** when giving an employee the applicable policy or credits.
5. use **File leave for an employee** for an authorized admin-filed request.
6. use **Review and cancel leave** for an existing application.

check the leave type, balance, status, covered dates, expiry, and open-payroll impact before changing a request or balance.
