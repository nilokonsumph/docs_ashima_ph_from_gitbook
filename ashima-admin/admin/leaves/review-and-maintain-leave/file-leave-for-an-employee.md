# File leave for an employee

use the employee leave details page to file a leave application on behalf of an employee who cannot submit it from the employee portal.

**Navigation:**\
go to **Leaves → Leave Balance**, open the employee, then select the leave application action.

## before you file

confirm that the employee has the correct leave type assigned, the effective start date has passed, and the requested dates do not conflict with existing leave or work rules.

## how do i file leave for an employee?

1. open the employee's leave details.
2. select the assigned leave type.
3. select the available action under **Apply Leave**. If the row shows **No Entitlement**, confirm the employee's entitlement and leave setup before continuing.
4. select the covered date or date range.
5. review the work schedule and requested duration.
6. enter the reason and required details.
7. upload supporting documents when required.
8. submit the application.

## what happens after submission?

the request enters the configured leave approval workflow unless the admin-initiated path approves it immediately under the company's rule. The requested credits are reflected in the appropriate pending or approved balance state.
