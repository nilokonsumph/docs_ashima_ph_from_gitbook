# Leave overview and history

use the leave overview and history pages to review employee leave activity, application status, dates, attachments, and downloadable records.

**Navigation:**\
go to **Leaves → Leave Overview** or **Leaves → Leave History**.

## what does the overview display?

the overview summarizes approved leave and current leave activity. Use it for a quick attendance check, then open the history or employee balance when you need the application or credit details.

## what does leave history display?

leave history lists applications with the employee, leave type, covered dates, duration, status, and available supporting files. The status tells you where the request is in its workflow; it does not replace the employee's balance ledger.

## how do i find a leave record?

1. open **Leave History**.
2. choose **All**, **Approved**, **Pending**, **Cancelled**, or **Rejected**.
3. search for an employee, select a leave type, and set the start and end dates.
4. open the employee or application record for more detail.
5. download the attachment when supporting documents are available.

## how do i download leave history?

1. apply the filters you want included.
2. open the download control.
3. select **XLS** or **CSV**.

the file follows the current filters. Review the period and status filters before using it as an attendance or payroll reference.
