# Workforce documents

use workforce documents to assign supported documents to an employee, review the employee's list, and open a print preview.

**Navigation:**\
go to **Utilities → Documents**.

### how do i assign a document?

1. search for the employee.
2. open the employee's document list.
3. click the assignment action.
4. select the document.
5. complete the required fields.
6. click **Save**.

before saving, confirm the employee, document type, effective or issue details, and any employee information that will appear in the output. The available fields depend on the selected document.

### what happens after assignment?

the document appears in the employee's list and becomes available for print preview. Remove an assignment only when the employee should no longer have that document record.

an assigned document uses employee information stored in Ashima. If the name, employment details, compensation information, or other displayed value is incorrect, update the owning employee record first and reopen the document.

### how do i print a document?

open the assigned document, select **Print Preview**, review the employee details, and use the browser print action when the output is correct.

### how do i correct or remove an assigned document?

open the employee's document list and select the available edit or removal action for that record. Review any printed or previously shared copy before replacing it. Removing an assignment from Ashima does not retrieve a copy that has already been printed or sent outside the platform.

### why might a document or employee be missing?

check your page privilege, employee visibility, confidential access, employee status, and whether the document type is enabled for the company. Document assignment is separate from Workflow approval unless the selected document process explicitly submits an approval request.
