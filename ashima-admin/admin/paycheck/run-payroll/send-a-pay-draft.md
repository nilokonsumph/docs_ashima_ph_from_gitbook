# Send a pay draft

use **Send Pay Draft** to give selected employees an employee-facing preview of an open payroll before approval and closing.

> \[!WARNING] a pay draft is not a closed payslip. Recalculate and review the payroll first. The page warns that continuing without recalculation can create discrepancies.

**Navigation:**\
go to **Paycheck → Pay Run → Payroll**, then open **View Payroll Masterlist** for an open pay run.

## what happens when i select send pay draft?

the current confirmation states that employees receive a copy of their pay-summary draft by email and can view the updating draft in the employee portal. The dialog includes an employee selector and **continue**.

the masterlist also displays **Last Sent** and **Sent Count** so the admin can see whether a draft batch has already been sent from that pay run.

## before you continue

1. run the required payroll recalculation.
2. use **Check for Pay Updates** and resolve employees still requiring recalculation.
3. review totals and Employee Pay Details.
4. select only the intended employees in the Pay Draft dialog.
5. confirm that sending email and portal access is appropriate for this test or live payroll.

## what should the employee understand?

the output is a draft of the current open payroll. It may change when the admin corrects source records, adjustments, exclusions, settings, or calculations before approval.
