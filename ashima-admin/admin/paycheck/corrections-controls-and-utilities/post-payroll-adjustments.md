# Post-payroll adjustments

use Post Payroll Adjustment (PPA) for an eligible correction to a previous closed payroll when the original pay run can no longer be changed.

**Navigation:**\
go to **Settings → Pay Run → Post Payroll Adjustment** to review the governing options. Start the eligible correction from its source Hours, Leave, Rest Day, or Overtime workflow.

## how does ppa work?

an approved correction is calculated and brought forward into a current open pay run for the next transaction date. The result can represent an underpayment or overpayment from the earlier closed payroll.

the current setting limits PPA to timesheet adjustments, missed time logs, missed rest-day requests, leaves, and missed overtime. It is not a general replacement for every late earning, deduction, or tax change.

## who can initiate a ppa?

* an admin can initiate PPA for an employee; the current setting describes admin-initiated PPA as automatically approved.
* employee-initiated PPA is optional. When enabled, the employee submits the request through the employee portal and the request follows its configured approval workflow.

## what controls eligibility?

**Settings → Pay Run → Post Payroll Adjustment** controls whether PPA is enabled, whether employees can initiate it, and how many previous closed payroll dates remain eligible. The reviewed test account allowed up to six previous payroll dates.

## before using ppa

1. confirm that the source payroll is closed.
2. confirm that the correction type is included in the current PPA setting.
3. verify whether the admin or employee should initiate it.
4. review the original dates, hours, request, and approval evidence.
5. after approval, verify the PPA result in the later open payroll and Employee Pay Details.

## rules and warnings

* PPA does not reopen or rewrite the original closed payslip.
* employee initiation and admin initiation follow different approval behavior.
* a PPA result is not final until the receiving open payroll is recalculated, reviewed, approved, and closed.
