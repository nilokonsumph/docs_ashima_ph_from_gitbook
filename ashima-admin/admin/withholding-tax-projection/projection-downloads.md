# Projection downloads

use projection downloads to review the projection dataset offline or prepare the supported import-format file.

**Navigation:**\
go to **Reports → Tax → Wtt Tool**, then open the available download control.

### what files are available?

* Excel provides the projection table in workbook format.
* CSV provides the projection table as comma-separated data.
* import format provides employee reference, payroll date, and amount fields for the supported adjustment workflow.

### how do i download projection data?

1. apply the employee and payroll filters.
2. click **Download**.
3. select the required file type.
4. review the employee scope and columns in the downloaded file.

the download reflects the projection state and filters available when it was generated. Recalculate first when employee compensation, payroll, tax, 13th Month, or adjustment data has changed.

### what should i check before upload?

confirm employee IDs, payroll date, and amount. The current import-format export may leave payroll date blank, so complete and validate the file before using an upload process.

### which file should i use?

* use **Excel** for review, reconciliation, and working notes;
* use **CSV** when a plain dataset is required; and
* use **import format** only as the starting structure for the supported adjustment upload.

do not upload an ordinary review download as though it were an import template. Keep column names and required identifiers unchanged in the import-format file.

### what should i do when the downloaded scope is wrong?

return to the WTT Tool, check the year, employee, payroll-group, and other active filters, then download again. Correct projection sources and recalculate before producing a replacement file; editing the downloaded value alone does not update Ashima.
