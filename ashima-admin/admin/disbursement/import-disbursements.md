# Import disbursements

Use the disbursement import when you need to add payment entries for many employees from one CSV file.

> Always start with the current Ashima template. Do not change the column names or upload an old template without checking its format.

**navigation:**\
Go to **Upload Manager → Disbursement**.

## what should you prepare?

The template includes the employee ID and the payment information required by the import. Cost center is optional when allowed by the template and must match an existing company cost center.

## how do you import entries?

1. Download the current CSV template.
2. Review the sample row and instructions in the file.
3. Enter one row for each required employee entry.
4. Keep employee IDs and configured names exactly as required.
5. Save the file as CSV.
6. Select the file on the import page.
7. Validate the file.
8. Review every validation result.
9. Correct rejected rows and validate again when needed.
10. Proceed with the upload only when the results are acceptable.

## what happens after validation?

Validation checks the file before entries are created. It does not replace your review of employee, amount, classification, and cost-center data.

## what happens after upload?

The uploaded entries are prepared for the disbursement workflow. Open the resulting record, review the totals, and recalculate before submission.
