# how do I set up desktop clock-in?

to enable desktop clock in turn ON the settings under **settings > hours > time entry > desktop clock in**

<figure><img src="../../../.gitbook/assets/Screenshot 2025-10-03 at 12.38.01 AM.png" alt=""><figcaption></figcaption></figure>

\
\
when employees log in to their ashima employee portal, a timeclock is displayed along with the corresponding **Time In** and **Time Out** buttons. this is the default method of recording work hours.&#x20;

<figure><img src="../../../.gitbook/assets/Screen Shot 2022-06-13 at 6.48.04 AM.png" alt=""><figcaption></figcaption></figure>

\
\
you can further secure or customize this process by enabling features such as photo capture and IP restrictions.<br>

#### how does photo capture work?

* this feature captures an employee’s photo when they clock in or out from their desktop portal.
* a webcam must be connected to the employee’s device.
* photos are stored with the timesheet record for reference.

{% hint style="info" %}
Ii photo capture is enabled, it becomes a required step - employees must have a working webcam on their desktop, and a photo will be taken before the time log is accepted.
{% endhint %}

#### how does IP restriction work for desktop clock-in?

* when enaabled IP restriction ensures employees can only clock in or out from **company-approved IP addresses**.
* this requires static IP addresses for your office networks.
*   to easily manage your IP's especiailly if you have multiple IP addresses assigned to multiple locations start by defining/creating IP locations on your location settings.

    * first, go to **settings > workforce > location & worksites** and add the IP locations you want to define.&#x20;



<figure><img src="../../../.gitbook/assets/Screenshot 2025-10-02 at 11.57.39 PM.png" alt=""><figcaption></figcaption></figure>

when creating a new location make sure to choose IP location on the drop down on where to use this for.<br>

<figure><img src="../../../.gitbook/assets/Screenshot 2025-10-02 at 11.58.02 PM.png" alt=""><figcaption></figcaption></figure>

* next, on the **settings > hours > time entry>desktop clock in**  add the IP's you want to be part of your white list. &#x20;
* on the time entry settings, if you add any IP location, the whitelist applies **globally** to all employees. all your employees will be able to clock in from the company-wide trusted IP addresses.<br>

<figure><img src="../../../.gitbook/assets/Screenshot 2025-10-02 at 11.44.37 PM.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Use this feature if you want to limit desktop clock-ins strictly to your company’s networks.
{% endhint %}

#### can i enable IP restriction for specific employees?&#x20;

* if you want certain employees to clock in only from specific IPs (that other employees cannot use), you can by enabling IP restriction to **employee level**
* to configure this go to the individual employee workforce profile, and click on  employee’s **time entry settings**, switch on **employee-level IP restriction**.

<figure><img src="../../../.gitbook/assets/Screenshot 2025-10-02 at 11.53.02 PM.png" alt=""><figcaption></figcaption></figure>



* add the specific IP address(es) you want to limit for that employee, choose the location you created to help you define the custom IP you assigned to this employee. &#x20;
* Once applied, the employee will only be able to clock in/out from the assigned IP address(es).

#### can I whitelist multiple IP addresses?

yes. if you need to whitelist more than one IP address, you can either:

* add them individually to the trusted IP list, or
* **upload multiple IPs** at once using the IP upload for faster setup.
