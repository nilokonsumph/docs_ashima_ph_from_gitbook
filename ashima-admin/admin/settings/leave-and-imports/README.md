# Leave and imports

use this section to configure leave rules and use supported upload templates and validation flows.

**Navigation:**\
go to **Settings → Leave and imports**.

leave setup controls policy, units, eligibility, accrual or assignment, negative balance, expiry, carryover, conversion, documents, and workflow. Employee assignment and transaction history remain separate from the reusable leave policy.

for imports, always start with the current template, preserve required headers and identifiers, validate the file, review every result, and correct rejected rows before proceeding. After an accepted import, review the affected records and recalculate or regenerate dependent outputs when needed.
