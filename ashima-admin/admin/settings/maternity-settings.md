# Maternity settings

### Maternity Benefit

Use **Maternity Benefit** to maintain the company's maternity-benefit policy settings for maternity-related leave handling.

**Navigation:** Go to **Settings → Leaves → Maternity Benefit**

#### What does this page display?

This page displays the maternity-benefit rule set under **maternity benefit settings**.

The settings control which maternity-related cases are included and which policy checks or document requirements apply.

#### What can I do from this page?

Use this page to define:

* whether standard maternity leave is included
* whether solo-parent maternity leave is included
* whether emergency termination or miscarriage cases are included
* whether contribution, childbirth timing, or prior-notice checks should be enforced
* whether maternity leave can be allocated, and up to how many days
* which supporting documents are required

#### What should administrators know about the maternity settings on this page?

The page stores four main rule groups:

* **Included maternity benefit types** — which maternity scenarios the company will process.
* **Eligibility and grant checks** — optional checks for contribution history, childbirth timing, and prior notice.
* **Allocation rule** — whether allocation is allowed and the maximum number of days allowed for allocation.
* **Document checklist** — whether documents are required, and which documents are part of the checklist.

The supported checklist can include items such as:

* **SSS Maternity Notification Form**
* **UMID or SSS biometrics ID Card**
* **Valid ID 1**
* **Valid ID 2**
* **Registered birth certificate**
* **Operating room record or surgical memorandum**
* **Obstetrical history** for miscarriage or emergency termination cases

#### What happens after I save?

The maternity-benefit rules are updated for the company and are then used by the maternity-related leave and approval flows that depend on this setup.

#### Rules, warnings, or behavior notes

* If you turn on a conditional maternity rule, its matching value becomes required.
* If you turn on allocation, the allowed number of allocation days is required.
* If you turn on the checklist, the supporting-document choices are part of the enforced policy.
