# Payroll settings

use this section for payroll groups and schedules, earnings, deductions, contributions, withholding tax, 13th Month, retro, and related payroll rules.

**Navigation:**\
go to **Settings → Payroll settings**.

### recommended approach

1. configure the company item or rule.
2. assign it to eligible employees when assignment is required.
3. confirm pay dates, schedules, tax treatment, and effective dates.
4. calculate or recalculate an open payroll.
5. review Employee Pay Details and reports.

settings changes do not rewrite closed payroll. Use the supported correction process for completed results.
