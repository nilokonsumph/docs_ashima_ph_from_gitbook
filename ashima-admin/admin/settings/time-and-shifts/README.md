# Time and shifts

use this section for time-entry methods, attendance interpretation, overtime, tardiness, breaks, holidays, rest days, and shift behavior.

**Navigation:**\
go to **Settings → Time and shifts**.

company settings provide default rules, while supported employee settings can override specific time-entry options. Review the company rule, employee restriction, assigned shift, request workflow, and payroll effect together.

after changing a rule, review affected timesheets and recalculate open payroll when attendance or paid time changes.
