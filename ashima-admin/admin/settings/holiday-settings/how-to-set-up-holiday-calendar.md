# how to set up holiday calendar

You have two options to set up the holiday calendar in ashima. <br>

1. **Use the default holiday calendar** provided by ashima.
2. **Upload a custom holiday list** using a CSV template.

#### How do I use the default holiday calendar?

**Q:** How do I accept the default list?\
**A:**

* Navigate to **Shifts → Holiday Schedule**.
* Click **“Yes, I’m good with the default holiday schedule — let’s roll!”**
* Review the national holidays provided and verify they align with your company’s holiday policy.

**Tip:** Finalize your 2024 holiday setup before your first payroll run of the year.
