# Earnings settings

## Allowance

Use this page to create the allowance types that can later be assigned to employees.

**Navigation:** Go to **Settings → Pay Check → Earnings → Allowance**

#### What does this page display?

This page displays the saved company allowance types and their payroll rules.

#### What can I do from this page?

You can:

* create an allowance type
* define its tax treatment and payroll behavior
* update an existing allowance type
* remove unused allowance types

#### What should administrators know about this page?

Use this page to define the allowance type only. The actual employee assignment still happens later in the employee payroll setup.

This page can control:

* allowance name
* tax treatment
* schedule or frequency
* amount logic
* whether the allowance remains payable during absence where that rule is supported

#### What happens later in payroll?

After the allowance type is assigned to an employee, payroll can show it later as:

* an allowance earning in payroll review
* part of payroll totals in the masterlist
* an allowance line or earnings-side grouped entry in the payslip

### De Minimis

Use this page to define the company de minimis rule that payroll will later apply to eligible employees.

**Navigation:** Go to **Settings → Pay Check → Earnings → De Minimis**

#### What does this page display?

This page displays the company de minimis setup, including the allowed type, release pattern, and tax-ceiling behavior.

#### What can I do from this page?

You can:

* define the de minimis type
* set the release pattern or schedule
* set the tax-exempt ceiling and excess behavior
* update the company rule when policy changes

#### What should administrators know about this page?

This page is not a simple employee earning list. It defines the company rule first, then eligible employees are given the de minimis setup later in employee payroll assignment.

#### What happens later in payroll?

Payroll reads this setting when deciding:

* how much de minimis is released
* how much stays non-taxable
* whether any excess moves into taxable payroll treatment

### Other Earnings

Use this page to create reusable other-earning types that can later be assigned to employees.

**Navigation:** Go to **Settings → Pay Check → Earnings → Other Earnings**

#### What does this page display?

This page displays the saved other-earning types and their payroll behavior.

#### What can I do from this page?

You can:

* create an other-earning type
* define whether it is taxable or non-taxable
* define whether it is recurring or one-time by setup
* update or remove unused earning types

#### What should administrators know about this page?

Use this page to create the earning type. Employee-level assignment or release still happens later.

This page is where the tax treatment matters most:

* **Taxable Other Earnings** increase taxable pay
* **Non-taxable Other Earnings** increase pay without going through the same taxable-pay treatment

#### What happens later in payroll?

After assignment or release, payroll can show the earning later in:

* payroll review
* masterlist totals and downloads
* the payslip as its own earning row or as an earnings-side grouped payroll entry, depending on how it was added
