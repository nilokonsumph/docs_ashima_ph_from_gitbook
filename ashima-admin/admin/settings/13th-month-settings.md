# 13th month settings

### 13th Month

Use this page to define the company 13th month rules used by the separate 13th month payroll process.

**Navigation:** Go to **Settings → Pay Check → Earnings → 13th Month**

#### What does this page display?

This page displays the company 13th month rule setup.

#### What can I do from this page?

You can review and maintain the company rules that affect:

* who is entitled
* what pay items are included
* how 13th month is treated later in the dedicated 13th month run

#### What should administrators know about this page?

This page does not assign a normal recurring earning to an employee. It defines the company rule layer used later when the admin runs the 13th month payroll process.

#### What happens later in payroll?

Payroll uses this setup during the separate **13th Month** process, then shows the result later in:

* the 13th month run review
* 13th month outputs and downloads
* the dedicated 13th month payslip
