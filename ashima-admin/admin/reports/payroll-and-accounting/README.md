# Payroll and accounting

use this section for Payroll Register, Payroll Variance, Accounting Entries, and Cost Structure reports.

**Navigation:**\
go to **Reports → Payroll and accounting**.

### choose the correct report

* **Payroll Register:** detailed employee payroll results for a selected run.
* **Payroll Variance:** comparison of payroll results or periods.
* **Accounting Entries:** payroll journal information.
* **Cost Structure:** payroll cost allocation and employee-level review.

review and recalculate the source payroll before generating final outputs. Correct discrepancies in the pay run, employee record, or owning source, then regenerate the report.
