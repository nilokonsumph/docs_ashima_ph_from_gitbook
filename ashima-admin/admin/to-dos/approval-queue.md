# Approval queue

use **Todo** to open requests assigned to you and complete the applicable review before approving or rejecting them.

**Navigation:**\
go to **Todo**.

### what does the queue display?

the Todo page groups pending work by request type and shows a badge count when matching items are available. The categories you see depend on your privileges, workflow assignment, enabled modules, and pending requests.

see To Do overview for the available request groups and how Workflow settings determine who receives them.

### how do i review a request?

1. open the request category.
2. search for the employee or use the available filters.
3. open the request or load its supporting details.
4. compare the request with its source record and company settings.
5. approve or reject only after completing the category-specific checks.

### what happens after a decision?

the request leaves the pending queue and its source module updates according to the decision. Approval may make the item available to payroll; rejection returns it to the applicable rejected or editable state.

some Timesheet items tied to a closed payroll cannot be approved. Ashima identifies these items in the queue and provides a separate rejection cleanup action. Review the affected count and records before using it.
