# Admin guide overview

use the Ashima Admin guide to set up employees and company rules, manage attendance and leave, run payroll, prepare payments, and review reports.

**Navigation:**\
open the guide section that matches the Ashima module you are using.

### where should i start?

| task                                                      | guide section                  |
| --------------------------------------------------------- | ------------------------------ |
| review work waiting for approval                          | **To Do's**                    |
| maintain employee information and access                  | **Workforce**                  |
| create shifts and employee schedules                      | **Shifts**                     |
| review logs, attendance, and overtime                     | **Hours**                      |
| manage leave, CTO, and maternity benefits                 | **Leaves**                     |
| calculate and complete payroll                            | **Paycheck**                   |
| prepare a separate employee payment                       | **Disbursement**               |
| review projected withholding tax                          | **Withholding tax projection** |
| generate payroll, statutory, workforce, and audit outputs | **Reports**                    |
| use documents and support tools                           | **Utilities**                  |
| configure company rules and approval routing              | **Settings**                   |

### how do the modules work together?

Ashima uses connected records. Employee and company settings influence shifts, time, leave, payroll, payment, and reporting.

1. configure the company rules and workflows in **Settings**.
2. maintain the employee's Workforce, compensation, assignment, and access records.
3. assign shifts and review Hours and Leave information.
4. calculate, review, and approve Paycheck or another payroll process.
5. prepare Disbursement or payment outputs when applicable.
6. generate reports from the completed source records.

correct information at its owning source page. Recalculate payroll or projections and regenerate reports after a source correction.

### how should i use warnings and status information?

read the prerequisites and warning notes before saving, deleting, recalculating, submitting, approving, closing, importing, or downloading. Draft, waiting-for-approval, rejected, approved, and closed records can allow different actions.

high-impact actions such as payroll closing, tax adjustments, employee separation, bulk imports, and payment-file generation should be reviewed by an authorized administrator before completion.

### why might my page look different?

available pages, fields, and actions depend on company setup, enabled modules, employee scope, confidential access, page privileges, record status, and Workflow assignment.
